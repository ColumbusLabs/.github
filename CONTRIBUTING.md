# Contributing

Thanks for considering a contribution to a Columbus Labs project.

## Before you begin

- Read the target repository's README and any project-specific contributing guide.
- Search existing issues and pull requests before starting work.
- For substantial features or architectural changes, open an issue first so we can align on scope.
- Keep changes focused. Unrelated refactors make review and release work harder.

## Pull requests

1. Create a focused branch from the repository's default branch.
2. Follow the project's existing style and architecture.
3. Add or update tests when behavior changes.
4. Run the checks documented by the repository.
5. Explain what changed, why it changed, and how you verified it.

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
